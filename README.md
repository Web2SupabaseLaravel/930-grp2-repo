# Event Management System

A full-stack web application for managing events, including creating, updating, and organizing events with a user-friendly interface.

## 🚀 Features
- Create and manage events
- User authentication (JWT)
- Interactive frontend interface
- Real-time data handling

## 🛠️ Tech Stack
- Backend: Laravel (PHP)
- Frontend: React.js
- Database: Supabase / PostgreSQL
- Authentication: JWT

## 📚 What I Learned
- Building a full-stack application using Laravel & React
- Working with APIs and JWT authentication
- Managing frontend-backend integration
- Handling real-world project structure and teamwork
